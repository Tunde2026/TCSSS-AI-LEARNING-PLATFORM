# AI Learning Platform

An AI-powered learning engine for Tomia Community Senior Secondary School
(TCSSS). Built around the cycle: **Learn → Visualize → Practice → Analyze → Adapt**.

## Stack
- Frontend: plain HTML / CSS / JS
- Backend: Node.js + Express
- Database: PostgreSQL (+ pgvector for retrieval)
- AI: Ollama (self-hosted) with optional cloud fallback providers
